Universal Woodworking Minecraft датапак
Автор:
OnixTheCat:

О:

Этот Minecraft датапак добавляет больше вариантов рецептов для пилорамы из мода TeamAbnormals Woodworks для большей совместимости с другими модами.

Датапак также добавляет некоторые QoL рецепты как для ванильного крафтинга, так и для пилорамы.


Совместимости:

- Another Furniture: Рецепты мебели;
- Farmer's Delight: Рецепты кладовых;
- Malum: Рецепты для модовых типов древесины и кастомных деревянных блоков;
- Wizard's Reborn: Рецепты для модовых типов древесины и кастомных деревянных блоков;
- Silly Oddities: Рецепты для совместимостей внутри мода.
