Pawscript

I've been working on Paw Paint DS for a while, and I needed a font for it. I don't like the default one from the development library, and it's only in English. I wanted to be able to translate text into other languages, so I created my own.

And I decided to publish this font so that others could also use it for their projects :3


Pawscript is a pixel font that was originally created for Paw Paint DS.
